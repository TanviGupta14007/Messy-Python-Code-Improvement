# Messy Python Code Improvement Using AI

## About the Project

This project demonstrates how AI-assisted coding tools can improve the readability and structure of an existing Python program while preserving its original output.

## Objectives

* Improve variable and function names.
* Remove unused imports.
* Create reusable functions.
* Use f-strings for formatted output.
* Apply Python coding standards through Cursor rules.
* Add a function to count students whose averages exceed the class average.

## Project Files

| File                     | Description                                                        |
| ------------------------ | ------------------------------------------------------------------ |
| `messy_py.py`            | Refactored version of the original program, preserving its output. |
| `improved_messy_code.py` | Improved version with the additional class-average feature.        |
| `original_output.txt`    | Reference output from the original program.                        |

## Technologies Used

* Python 3
* Cursor AI

## How to Run

Install Python 3, download or clone this repository, and run the following commands from the project directory:

```bash
python messy_py.py
```

To run the version with the additional feature:

```bash
python improved_messy_code.py
```

## Learning Outcome

The project demonstrates AI-assisted refactoring, reusable functions, descriptive naming, coding standards, and output validation.
